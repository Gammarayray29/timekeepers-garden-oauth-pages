Timekeeper's Garden Artwork Sync

Timekeeper's Garden Artwork Sync is a project utility that copies PNG artwork from the private Timekeeper's Garden GitHub repository to a designated folder in the project owner's Google Drive.

The synchronization runs through GitHub Actions and uses Google OAuth to access Google Drive. Updated artwork is uploaded, and replaced older copies are moved into an Archive folder when possible. Files removed from the GitHub repository are not automatically deleted from Drive.

This utility is intended for the project owner's personal workflow; it is not a general public file-hosting or consumer service.
